# 推荐系统完整启动与建设手册

状态：`runbook` + `current-code`

本目录只处理**从现有代码到真实数据和生产化**。旧的本地 JAX Demo 已移除；如果需要了解历史上手路径，请看[从零跑起来](../getting-started/)。

## 先记住三件事

- 旧 Demo 使用模拟数据和随机权重，当前已移除；不要把历史 Demo 结果当作模型效果。
- 协议字段存在不等于功能已接入；当前行为以代码和模块专题为准。
- 可以暂时关闭个性化，但不能绕过删除、审核、拉黑、静音和曝光记录等安全与数据边界。

## 运行层级

| 层级 | 证明什么 | 外部业务依赖 |
| --- | --- | --- |
| L0 编译 | 代码和工具链可用 | 无 |
| L1 模型 | Phoenix 精排/召回可推理 | 无 |
| L2 Demo | Thunder、Phoenix、Home Mixer 可通信并返回 Feed | 模拟数据 |
| L3 真实数据 MVP | 用户、内容、关系、审核数据可用 | 需要 Adapter |
| L4 生产系统 | 认证、监控、容量、灰度、回滚和数据闭环 | 需要完整平台能力 |

## 维护边界

- 操作命令以本目录、模块 README 和仓库现存脚本为准；模块导读不要复制命令。
- 真实数据合同放在 [`../implementation/`](../implementation/)；训练目标设计放在 [`../training/`](../training/)；持续运维放在 [`../operations/`](../operations/)。
- 本目录的生产结论需要结合真实部署环境复核，不能把模板或设计建议当作已完成能力。
