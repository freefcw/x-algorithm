## 0. 一句话用法 + 依赖接入顺序

**这份清单不是让你一次填完的，是按上线前评审的节奏逐项打勾的。** 推荐的依赖接入顺序（和业务价值/风险排序一致）：

```mermaid
flowchart LR
    subgraph 第一优先["① 先接这些，缺了就不能上线"]
        A1[用户身份/权限]
        A2[内容服务]
        A3[内容安全/审核]
    end
    subgraph 第二优先["② 再接这些，决定体验下限"]
        B1[关系服务
关注/拉黑/静音]
        B2[行为/曝光日志]
    end
    subgraph 第三优先["③ 最后接这些，决定上限"]
        C1[UAS 行为序列]
        C2[Phoenix 模型]
        C3[Kafka/Thunder]
    end
    第一优先 --> 第二优先 --> 第三优先
```

顺序不能反：**先证明内容安全、能返回，再谈个性化，最后才谈实时和规模。**
