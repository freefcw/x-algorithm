# 从零跑起来

状态：`current-code`（每条命令都在仓库当前代码上验证过）

这组文档是整个仓库的推荐入口：不预设推荐系统背景，按顺序读、照着敲命令，从装环境一路走到"请求一次推荐 Feed 并拿到排序结果"。

| 顺序 | 文档 | 耗时 | 你会得到什么 |
| --- | --- | --- | --- |
| 0 | [这个项目是什么](./00-这个项目是什么.md) | 5 分钟 | 大白话理解四个模块的分工，知道系统能跑到什么程度 |
| 1 | [准备环境](./01-准备环境.md) | 10 分钟 | Rust + protoc + uv 装齐，编译测试通过 |
| 2 | [第一步：跑通模型演示](./02-第一步-跑通模型演示.md) | 5 分钟 | 本地看到精排/召回模型的推理输出 |
| 3 | [第二步：把模型变成服务](./03-第二步-把模型变成服务.md) | 10 分钟 | 用 curl 调用打分与召回 HTTP 接口 |
| 4 | [第三步：训练自己的模型](./04-第三步-训练自己的模型.md) | 15 分钟起 | 产出 checkpoint 并让服务加载 |
| 5 | [第四步：跑通完整推荐链路](./05-第四步-跑通完整推荐链路.md) | 10 分钟 | 一条命令端到端跑通，返回混合排序的 Feed |
| 6 | [从演示到真实系统](./06-从演示到真实系统.md) | 阅读 | 接真实数据的缺口清单与推进顺序 |

急性子版本：装好 Rust/protoc/uv 后，在仓库根目录执行

```bash
cd phoenix && uv sync --group service && cd .. && ./scripts/run_demo.sh
```
