# 第三步：训练自己的模型

> **这篇解决什么问题**：X 没有开源训练好的权重，这一步教你自己训练一份，让模型输出不再是"五五开"。
> **读完你能做到什么**：跑通训练循环，产出 checkpoint 文件，并让服务加载它。
> **前置条件**：完成 [01-准备环境](./01-准备环境.md)；不需要 GPU（CPU 能训练小规模配置）。

以下命令都在 `phoenix/` 目录下执行。

## 先用模拟数据跑通训练循环

不需要准备任何数据文件：

```bash
uv run scripts/train_ranker.py --steps 200 --batch-size 8
```

预期看到 loss 逐步下降，最后输出产物路径：

```text
step   200 / 200  loss=...
模型参数已保存到 ./checkpoints/model_params_step200.npz
嵌入表已保存到 ./checkpoints/embedding_tables.npz
=== 训练完成 ===
```

两个产物文件的分工：

| 文件 | 内容 |
| --- | --- |
| `model_params_step200.npz` | Transformer 模型权重 |
| `embedding_tables.npz` | 三张哈希嵌入表（用户/帖子/作者 ID → 向量） |

召回模型同理：`uv run scripts/train_retrieval.py --steps 200`，默认写到 `./checkpoints_retrieval/retrieval_params_step*.npz`（和精排的 `./checkpoints/` 不是同一个目录）。

> 模拟数据的标签是随机生成的，训出来的模型没有业务意义——这一步的价值是**验证训练管道**（数据加载、损失函数、checkpoint 保存/恢复）都能工作。

## 用真实（或仿真）行为数据训练

真正有意义的训练需要三类数据：用户行为日志（谁在什么时间对哪条帖子做了什么）、帖子元数据、用户元数据。仓库提供了完整的工具链：

```bash
# 1. 生成一批仿真业务数据（也可以换成你自己导出的数据）
uv run examples/generate_example_data.py

# 2. 把业务数据加工成训练样本（Parquet 格式）
# --behavior-dir / --post-meta 必填，路径对应上一步的默认输出
uv run data_preprocessor.py \
  --behavior-dir data/behavior_logs \
  --post-meta data/post_metadata.parquet \
  --date 2024-01-01

# 3. 用真实样本训练
uv run scripts/train_ranker.py --data-dir ./data/training_samples --steps 2000

# 数据量大时用流式模式，内存占用与数据集大小无关
uv run scripts/train_ranker.py --data-dir ./data/training_samples --streaming --steps 20000
```

字段格式、样本构造规则、增量训练、定时任务等完整说明见 [phoenix/docs/训练指引.md](../../phoenix/docs/训练指引.md)（操作手册）和 [phoenix/docs/真实数据接入指引.md](../../phoenix/docs/真实数据接入指引.md)（字段规范）。`train_ranker.py` 的全部命令行参数速查见 [训练性能系列的使用指南](../../phoenix/docs/archive/train_ranker_perf/05-使用指南.md)。

## 让服务加载你的模型

HTTP 服务：

```bash
RANKER_CHECKPOINT_PATH=./checkpoints/model_params_step200.npz \
  uv run scripts/run_services.py ranker
```

gRPC 网关（供完整链路使用）：

```bash
uv run scripts/run_grpc_gateway.py \
  --ranker-checkpoint checkpoints/model_params_step200.npz \
  --emb-tables checkpoints/embedding_tables.npz
```

启动日志里 `ranker=model_params_step200.npz` 代替了 `ranker=random`，说明加载成功。

> 常见坑：checkpoint 是 `.npz` 格式（numpy 压缩包），不是 `.pkl`。模型权重和嵌入表要配套使用——它们是同一次训练的产物。
