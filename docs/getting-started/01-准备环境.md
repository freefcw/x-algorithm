# 准备环境

> **这篇解决什么问题**：装齐三个工具，把仓库编译通过。
> **读完你能做到什么**：`cargo build` 和 `uv sync` 都能成功。
> **前置条件**：macOS 或 Linux，能上网。

## 需要装什么

| 工具 | 干什么用 | 安装方式 |
| --- | --- | --- |
| Rust 工具链（含 `cargo`） | 编译 thunder / home-mixer | [rustup.rs](https://rustup.rs/)：`curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` |
| `protoc`（Protobuf 编译器） | 编译服务之间的通信协议 | macOS：`brew install protobuf`；Ubuntu：`apt install protobuf-compiler` |
| `uv`（Python 包管理器） | 管理 phoenix 的 Python 环境 | `curl -LsSf https://astral.sh/uv/install.sh \| sh` |

不需要单独装 Python：phoenix 要求 Python ≥ 3.11，`uv` 会自动下载合适的解释器。也**不需要** Kafka、Redis、GPU——演示链路都不依赖它们。

## 编译 Rust 部分

在仓库根目录执行：

```bash
cargo build --workspace
```

第一次会下载依赖并编译，几分钟属于正常。预期最后看到：

```text
Finished `dev` profile [unoptimized + debuginfo] target(s) in ...
```

如果报错提示找不到 `protoc`，说明第 2 个工具没装好。

## 准备 Python 部分

```bash
cd phoenix
uv sync --dev --group service
```

`--dev` 装测试工具，`--group service` 装 HTTP/gRPC 服务依赖（后面的步骤都会用到）。预期看到类似：

```text
Installed XX packages in ...
```

## 验证

```bash
# 仓库根目录：Rust 测试应全部通过
cargo test --workspace

# phoenix 目录：Python 测试应全部通过
cd phoenix && uv run pytest
```

两条命令都以 `ok` / `passed` 结尾，环境就绪。下一篇：[02-第一步-跑通模型演示](./02-第一步-跑通模型演示.md)。

## 常见问题

- **`uv run` 报缓存权限错误**（多见于沙箱环境）：改用 `UV_CACHE_DIR=/tmp/uv-cache uv run ...`。
- **公司网络下载依赖慢**：Rust 可配置 crates.io 镜像，uv 可设置 `UV_INDEX_URL`。
