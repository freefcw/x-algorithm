# 第一步：跑通模型演示

> **这篇解决什么问题**：不接任何外部系统，5 分钟看到两个 AI 模型（精排、召回）真的在算东西。
> **读完你能做到什么**：本地运行模型推理，并看懂输出为什么长那样。
> **前置条件**：完成 [01-准备环境](./01-准备环境.md)。

以下命令都在 `phoenix/` 目录下执行。

## 跑精排模型（给帖子打分）

```bash
uv run scripts/run_ranker.py
```

脚本会现场编一个用户（带浏览历史）和 8 条候选帖子，送进 Transformer 模型，输出每条帖子的 19 种行为概率——"会点赞吗？会回复吗？会举报吗？"预期看到：

```text
排名 1:
  预测互动概率:
    Favorite Score          : ██████████░░░░░░░░░░ 0.500
    Reply Score             : ██████████░░░░░░░░░░ 0.500
    ...
演示结束!
```

**所有概率都是 0.500 是正常的，不是坏了。** 因为模型权重是随机初始化的（X 没有开源训练好的权重），一个没学过任何东西的模型对一切都回答"五五开"。这一步验证的是**计算链路通了**：数据格式、张量形状、注意力掩码都正确。想让分数变得有意义，要到[第三步](./04-第三步-训练自己的模型.md)训练自己的权重。

## 跑召回模型（从海量帖子里海选）

```bash
uv run scripts/run_retrieval.py
```

脚本模拟「从 1000 条帖子里挑出与用户最匹配的 Top-K」（脚本内同时演示 2 个用户）：把用户编码成向量，把每条帖子也编码成向量，然后算相似度取最高的。预期看到按相似度排序的帖子列表。

## 跑真实数据格式演示（可选）

```bash
uv run scripts/run_real_data_demo.py
```

演示"业务字段（用户 ID、帖子 ID、行为日志）如何变成模型输入"，是理解[真实数据接入](../../phoenix/docs/真实数据接入指引.md)的入门示例。

## 这一步你验证了什么

| 验证点 | 说明 |
| --- | --- |
| JAX/Haiku 环境正常 | 模型能初始化、能前向计算 |
| 精排模型结构正确 | 输入"用户+历史+候选"，输出每条候选的行为概率 |
| 召回模型结构正确 | 双塔（用户塔、物品塔）+ 向量相似度检索 |
