# 双塔模型输入输出原理详解

## 📋 概述

双塔模型（Two-Tower Model）是现代推荐系统中最重要的召回架构之一。它通过将用户和物品分别映射到同一向量空间，实现高效的相似度计算和大规模检索。本文档结合理论基础、相关论文和 Phoenix 项目实践，详细解析双塔模型的输入输出原理。

---

## 🧠 理论基础

### 核心思想

双塔模型的核心思想是将**用户-物品交互**问题转化为**向量相似度**问题：

```
用户特征 → User Tower → 用户向量
物品特征 → Item Tower → 物品向量
相似度 = 用户向量 · 物品向量
```

### 关键优势

1. **计算效率**：物品向量可离线预计算，在线仅需计算用户向量
2. **可扩展性**：支持百万级甚至亿级物品库的快速检索
3. **解耦设计**：用户塔和物品塔可独立优化和部署
4. **实时性**：新用户可立即获得推荐，无需重新训练

### 相关论文

#### 1. **"Two-Tower Deep Match Models for Document Recommendation"** (2019)
- **贡献**：首次系统性地提出双塔架构用于文档推荐
- **核心创新**：用户塔处理用户行为序列，物品塔处理文档内容
- **影响**：奠定了现代双塔模型的基础架构

#### 2. **"Embedding-based Retrieval in Facebook Search"** (2020)
- **贡献**：将双塔模型应用于大规模搜索场景
- **技术亮点**：
  - 使用最大内积搜索（MIPS）优化检索效率
  - 引入负采样策略提升模型判别能力
- **工程价值**：证明了双塔模型在十亿级规模下的可行性

#### 3. **"Approximate Nearest Neighbor Negative Contrastive Learning for Dense Text Retrieval"** (2021)
- **贡献**：提出对比学习框架训练双塔模型
- **核心方法**：
  - 使用难负样本挖掘
  - 引入InfoNCE损失函数
- **效果**：显著提升了向量表示的质量

### 设计原则

#### 1. **向量空间对齐**
- 用户塔和物品塔必须输出到**同一维度**的向量空间
- 使用**L2归一化**确保向量在单位超球面上
- 点积相似度等价于余弦相似度

#### 2. **独立编码**
- 用户塔专注于用户兴趣建模
- 物品塔专注于内容特征提取
- 两塔之间**无直接交互**，仅在相似度计算时相遇

#### 3. **非对称设计**
- **用户塔**：通常更复杂，处理序列信息（如历史行为）
- **物品塔**：通常相对简单，处理静态特征（如内容、作者）

## 📊 输入输出详解

### 用户塔（User Tower）

#### 输入结构

**1. 原始特征输入**
```python
# RecsysBatch - 用户相关特征
user_hashes: jax.Array              # [B, num_user_hashes] - 用户ID哈希
history_post_hashes: jax.Array      # [B, S, num_item_hashes] - 历史物品ID
history_author_hashes: jax.Array    # [B, S, num_author_hashes] - 历史作者ID
history_actions: jax.Array          # [B, S, num_actions] - 历史互动行为
history_product_surface: jax.Array  # [B, S] - 历史场景信息
```

**2. 预查询嵌入**
```python
# RecsysEmbeddings - 对应的嵌入向量
user_embeddings: jax.Array          # [B, num_user_hashes, D] - 用户嵌入
history_post_embeddings: jax.Array  # [B, S, num_item_hashes, D] - 历史物品嵌入
history_author_embeddings: jax.Array# [B, S, num_author_hashes, D] - 历史作者嵌入
```

#### 处理流程

**步骤1：特征聚合**
```python
# 用户特征聚合 - block_user_reduce
user_embedding, user_padding_mask = block_user_reduce(
    user_hashes,                    # [B, num_user_hashes]
    user_embeddings,                # [B, num_user_hashes, D]
    num_user_hashes=2,              # 哈希函数数量
    emb_size=128,                   # 目标维度
)
# 输出: user_embedding [B, 1, D], user_padding_mask [B, 1]

# 历史特征聚合 - block_history_reduce
history_embedding, history_padding_mask = block_history_reduce(
    history_post_hashes,            # [B, S, num_item_hashes]
    history_post_embeddings,        # [B, S, num_item_hashes, D]
    history_author_embeddings,      # [B, S, num_author_hashes, D]
    history_product_surface_embeddings,  # [B, S, D]
    history_actions_embeddings,     # [B, S, D]
    num_item_hashes=2,
    num_author_hashes=2,
    emb_size=128,
)
# 输出: history_embedding [B, S, D], history_padding_mask [B, S]
```

**步骤2：序列构建**
```python
# 拼接用户和历史序列
embeddings = jnp.concatenate([
    user_embedding,     # [B, 1, D] - 用户信息
    history_embedding   # [B, S, D] - 历史行为序列
], axis=1)
# 输出: embeddings [B, 1+S, D]

padding_mask = jnp.concatenate([
    user_padding_mask,     # [B, 1]
    history_padding_mask   # [B, S]
], axis=1)
# 输出: padding_mask [B, 1+S]
```

**步骤3：Transformer编码**
```python
# 输入Transformer进行时序建模
model_output = self.model(
    embeddings.astype(self.fprop_dtype),  # [B, 1+S, D]
    padding_mask,                          # [B, 1+S]
    candidate_start_offset=None,           # 用户塔无需候选隔离
)
user_outputs = model_output.embeddings  # [B, 1+S, D]
```

**步骤4：池化与归一化**
```python
# Mean Pooling - 对所有有效位置取平均
mask_float = padding_mask.astype(jnp.float32)[:, :, None]  # [B, 1+S, 1]
user_embeddings_masked = user_outputs * mask_float
user_embedding_sum = jnp.sum(user_embeddings_masked, axis=1)  # [B, D]
mask_sum = jnp.sum(mask_float, axis=1)  # [B, 1]
user_representation = user_embedding_sum / jnp.maximum(mask_sum, 1.0)

# L2 归一化 - 确保向量在单位超球面上
user_norm_sq = jnp.sum(user_representation**2, axis=-1, keepdims=True)
user_norm = jnp.sqrt(jnp.maximum(user_norm_sq, EPS))
user_representation = user_representation / user_norm
# 最终输出: user_representation [B, D]
```

#### 输出格式

```python
# 用户塔最终输出
user_representation: jax.Array  # [B, D] - L2归一化的用户向量
# 特点:
# - 每个用户对应一个128维向量
# - 向量模长为1（L2归一化）
# - 编码了用户的兴趣偏好和行为模式
```

### 物品塔（Item Tower）

#### 输入结构

**1. 原始特征输入**
```python
# RecsysBatch - 物品相关特征
candidate_post_hashes: jax.Array      # [B, C, num_item_hashes] - 候选物品ID
candidate_author_hashes: jax.Array    # [B, C, num_author_hashes] - 候选作者ID
candidate_product_surface: jax.Array  # [B, C] - 候选场景信息
```

**2. 预查询嵌入**
```python
# RecsysEmbeddings - 对应的嵌入向量
candidate_post_embeddings: jax.Array    # [B, C, num_item_hashes, D]
candidate_author_embeddings: jax.Array  # [B, C, num_author_hashes, D]
```

#### 处理流程

**步骤1：特征拼接**
```python
# 拼接物品和作者嵌入
post_author_embedding = jnp.concatenate([
    candidate_post_embeddings,    # [B, C, num_item_hashes, D]
    candidate_author_embeddings,  # [B, C, num_author_hashes, D]
], axis=2)
# 输出: post_author_embedding [B, C, num_item_hashes+num_author_hashes, D]
```

**步骤2：MLP映射**
```python
class CandidateTower(hk.Module):
    def __call__(self, post_author_embedding):
        # 调整输入形状，合并哈希维度
        if len(post_author_embedding.shape) == 4:
            B, C, _, D = post_author_embedding.shape
            post_author_embedding = jnp.reshape(post_author_embedding, (B, C, -1))
        # 输入: [B, C, (num_item_hashes+num_author_hashes) * D]
        
        # 第一层线性变换 + SiLU激活
        hidden = jnp.dot(post_author_embedding, proj_1)  # [B, C, emb_size*2]
        hidden = jax.nn.silu(hidden)
        
        # 第二层线性变换
        candidate_embeddings = jnp.dot(hidden, proj_2)  # [B, C, emb_size]
        
        # L2 归一化
        candidate_norm = jnp.sqrt(jnp.sum(candidate_embeddings**2, axis=-1, keepdims=True))
        candidate_representation = candidate_embeddings / candidate_norm
        
        return candidate_representation  # [B, C, D]
```

#### 输出格式

```python
# 物品塔最终输出
candidate_representation: jax.Array  # [B, C, D] - L2归一化的物品向量
# 特点:
# - 每个物品对应一个128维向量
# - 向量模长为1（L2归一化）
# - 编码了物品的内容特征和属性信息
```

## 🔄 相似度计算与检索

### 相似度计算

#### 点积相似度
```python
# 用户向量与物品向量的点积
# user_representation: [B, D]
# corpus_embeddings: [N, D] (全量物品库)
# scores: [B, N] - 每个用户对每个物品的相似度分数

scores = jnp.matmul(user_representation, corpus_embeddings.T)
```

#### 数学原理
由于向量经过L2归一化：
```
||u|| = 1, ||v|| = 1
点积: u · v = ||u|| ||v|| cos(θ) = cos(θ)
```
因此点积等价于余弦相似度，值域为[-1, 1]。

### Top-K检索

#### 实现方式
```python
# 获取Top-K最相似的物品
top_k_scores, top_k_indices = jax.lax.top_k(scores, top_k)

# 输出:
# top_k_scores: [B, K] - Top-K相似度分数
# top_k_indices: [B, K] - Top-K物品索引
```

## 🎯 关键技术细节

### 1. 哈希嵌入系统

#### 设计动机
传统嵌入表在大规模场景下的问题：
- **参数爆炸**：100万物品 × 128维 = 1.28亿参数
- **内存占用**：约500MB（float32）
- **冷启动**：新物品无法处理

#### 多哈希解决方案
```python
# 原始：vocab_size × emb_size 参数
# 多哈希：hash_table_size × num_hashes × emb_size 参数

# 示例：100万物品 → 2个哈希函数 × 1万表大小
hash_table_size = 10000
num_hashes = 2
emb_size = 128
total_params = hash_table_size * num_hashes * emb_size  # 256万参数

# 参数减少：1.28亿 → 256万（减少98%）
```

#### 哈希函数设计
```python
def multi_hash_embedding(item_id, num_hashes, hash_table_size):
    """多哈希嵌入查询"""
    embeddings = []
    for i in range(num_hashes):
        # 不同的哈希函数
        hash_val = hash_function(item_id, seed=i) % hash_table_size
        embedding = embedding_table[i][hash_val]
        embeddings.append(embedding)
    
    # 聚合多个哈希嵌入
    return aggregate_embeddings(embeddings)
```

### 3. 负采样策略

#### 随机负采样
```python
def random_negative_sampling(user_id, positive_items, num_negatives):
    """随机负采样"""
    all_items = get_all_items()
    negative_items = random.sample(
        [item for item in all_items if item not in positive_items],
        num_negatives
    )
    return negative_items
```

#### 难负采样
```python
def hard_negative_sampling(user_vector, item_vectors, num_negatives):
    """难负采样：选择与用户向量最相似的负样本"""
    similarities = jnp.dot(user_vector, item_vectors.T)
    # 排除正样本，选择最相似的负样本
    hard_negatives = jax.lax.top_k(similarities, num_negatives)
    return hard_negatives.indices
```

#### 对比学习损失
```python
def contrastive_loss(user_vector, positive_vector, negative_vectors, temperature=0.1):
    """InfoNCE对比损失"""
    # 正样本相似度
    pos_sim = jnp.dot(user_vector, positive_vector) / temperature
    
    # 负样本相似度
    neg_sims = jnp.dot(user_vector, negative_vectors.T) / temperature
    
    # 计算损失
    logits = jnp.concatenate([pos_sim[None], neg_sims])
    labels = jnp.array([0] + [1] * len(neg_sims))
    loss = jax.nn.cross_entropy_loss(logits, labels)
    
    return loss
```

```python
# 动态批次大小调整
def get_optimal_batch_size(model_size, memory_limit):
    """根据模型大小和内存限制计算最优批次大小"""
    estimated_memory_per_sample = model_size * 4  # bytes
    max_batch_size = memory_limit // estimated_memory_per_sample
```

#### 向量化计算
```python
# 向量化相似度计算
def batch_similarity_computation(user_vectors, item_vectors):
    """批量计算相似度矩阵"""
    # user_vectors: [B, D]
```
